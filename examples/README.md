# Code Examples

This directory contains practical code examples demonstrating the best practices outlined in the main guide.

## Available Examples

### 1. Basic Agent Patterns
- `reactive_agent.py` - Simple reactive agent implementation
- `deliberative_agent.py` - Deliberative agent with planning
- `hybrid_agent.py` - Hybrid agent combining reactive and deliberative approaches

### 2. Security
- `input_validation.py` - Input validation and sanitization
- `prompt_injection_guard.py` - Prompt injection prevention

### 3. Performance
- `caching_example.py` - Response caching implementation
- `rate_limiting.py` - API rate limiting and backoff

### 4. Monitoring
- `structured_logging.py` - Structured logging setup
- `metrics_collection.py` - Metrics collection and reporting

### 5. Error Handling
- `error_handling.py` - Comprehensive error handling patterns
- `circuit_breaker.py` - Circuit breaker implementation

## Usage

Each example is self-contained and includes:
- Clear comments explaining the implementation
- Usage examples
- Best practices demonstrated

Run examples individually:
```bash
python examples/reactive_agent.py
```

## Requirements

Most examples require:
- Python 3.8+
- See individual files for specific dependencies
